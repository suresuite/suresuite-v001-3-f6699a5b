# `docs/data/` — the single archive for data facts

**No data fact is authored in more than one place.** If a fact exists in code, the
docs render it; anything hand-written here must be a fact that exists nowhere else.
That rule is invariant I1, and the CI gate (WP 1.4) enforces it.

## Files

| File | Status | What it is |
|---|---|---|
| `IMPLEMENTATION-PLAN.md` | **AUTHORED** | **The plan.** Architecture, defects, transparency standard, documentation plan, 26 work packages, verification SQL, drift log. The only place file:line evidence lives. |
| `PROMPTS.md` | AUTHORED | One execution prompt per work package. Cites the plan by section and defect ID; restates nothing. |
| `tables/*.md` | GENERATED *(WP 1.4)* | One page per table, rendered from `data-contract.generated.json`. Do not edit — `npm run contract:check` fails on drift. |
| `field-mapping.md` | AUTHORED *(pending WP 0.3)* | Moving from `docs/data-simulation-mapping.md`. |
| `lifecycle.md` | AUTHORED *(pending WP 0.3)* | Moving from `docs/simulation-data-lifecycle.md`. |

## Start here

- **Building something?** `IMPLEMENTATION-PLAN.md` §1, then the WP you are on.
- **Running a work package?** `PROMPTS.md` — preamble plus one prompt, one session.
- **Want the architecture?** `IMPLEMENTATION-PLAN.md` §2, or the figures.
- **Want to know why the old docs were replaced?** §6.1, and defects D21/D22 in §4.
